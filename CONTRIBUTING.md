# Contributing to TeamSync

Thank you for your interest in contributing!

## Getting Started

1. Fork the repository
2. Create a feature branch

```bash
git checkout -b feature/my-feature
```

3. Make your changes
4. Run the tests

```bash
./mvnw test
```

5. Commit using descriptive commit messages

```bash
git commit -m "feat: add project member search"
```

6. Push your branch

```bash
git push origin feature/my-feature
```

7. Open a Pull Request

## Code Style

- Follow Checkstyle rules.
- Keep methods focused and concise.
- Write unit tests for new functionality.

## Reporting Issues

Use the provided issue templates when reporting bugs or requesting features.
